## Network code generated by ST Edge AI: ST SLA0104

`cynipsnet_v1.0/libcynipsnet.a` contains compiled ST Edge AI Core output. Its
`network.h` and `stai_network.h` expose the public interface. These files
remain STMicroelectronics software under SLA0104
([`LICENSES/LicenseRef-ST-SLA0104.txt`](../../../LICENSES/LicenseRef-ST-SLA0104.txt)).
SLA0104 does not allow them to be put under an open-source or Creative Commons
license and requires them to run only on ST devices, so the CC license above
does not cover them. The original generated C sources are kept privately;
the distributed archive and headers omit internal diagnostic metadata.
Modifications Copyright (c) 2026 Nikita Prismakov.

`network_shape.h`, `CMakeLists.txt`, `README.md` and all of `none/` are the
owner's code and documentation under Apache-2.0 like the rest of the
repository.

## Training data

The weights were trained on the datasets below. None of them is part of this
repository.

| Dataset | Used as | License |
|---|---|---|
| LibriSpeech | speech | CC BY 4.0 |
| VoiceAssistant-400K | speech | Apache-2.0 |
| DNS Challenge (noise from Freesound) | noise | CC BY 4.0 |
| FSD50K (selection) | noise | CC0 / CC BY per clip |

- **LibriSpeech** — ASR corpus by Vassil Panayotov, Guoguo Chen, Daniel Povey
  and Sanjeev Khudanpur (<https://www.openslr.org/12/>), derived from LibriVox
  audiobooks. V. Panayotov, G. Chen, D. Povey and S. Khudanpur, "LibriSpeech:
  an ASR corpus based on public domain audio books", ICASSP 2015.
- **VoiceAssistant-400K** — gpt-omni/VoiceAssistant-400K
  (<https://huggingface.co/datasets/gpt-omni/VoiceAssistant-400K>), Apache-2.0.
- **DNS Challenge** — Microsoft Deep Noise Suppression Challenge
  (<https://github.com/microsoft/DNS-Challenge>), noise clips originating from
  Freesound; data licensed under CC BY 4.0. C. K. A. Reddy et al., "The
  INTERSPEECH 2020 Deep Noise Suppression Challenge: Datasets, Subjective
  Testing Framework, and Challenge Results", INTERSPEECH 2020.
- **FSD50K** — E. Fonseca, X. Favory, J. Pons, F. Font and X. Serra,
  "FSD50K: An Open Dataset of Human-Labeled Sound Events", IEEE/ACM TASLP 2022
  (<https://zenodo.org/record/4060432>), clips from Freesound. Only clips
  under CC0 or CC BY were used; CC BY-NC clips were excluded. The author,
  the title and the license of every clip are given in the per-clip metadata
  published with the dataset at the link above.
